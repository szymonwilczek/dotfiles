# Academic & Citation Management

This module provides an academic research and citation environment in my Emacs, with:

- **Citar & Citar-Org**
- **Zotero & Local Storage**: Linked PDF storage and literature notes indexing (`~/references/`, `~/Zotero/storage`)
- **LaTeX Integration**
