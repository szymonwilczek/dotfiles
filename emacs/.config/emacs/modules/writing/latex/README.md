# LaTeX Authoring Environment

This module provides a LaTeX typesetting setup powered by **AUCTeX**, with:

- `latexmk`, `pdflatex`, `xelatex`, `lualatex`
- viewer integration (`mupdf` / `doc-view`)
- font-locking, syntax folding, and math macro expansion
